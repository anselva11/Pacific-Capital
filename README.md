# Blackridge Capital

A professional trading platform and brokerage dashboard built with Next.js, React, TailwindCSS, and PostgreSQL.

## Features
- Real-time Market Data & Charts (Lightweight Charts)
- Trading Interface (Order Book, Market/Limit/Stop orders)
- Portfolio Management & Asset Allocation
- AI Trading Assistant
- News & Earnings Calendar
- Copy Trading Leaderboards
- Referral System

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
